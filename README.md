# Лабораторная работа 2 — геометрический фрактал

Приложение на Python с интерактивной визуализацией Т-квадрата.

## Запуск

Требуется Python 3 с Tkinter (обычно входит в стандартную поставку Python):

```powershell
python main.py
```

## Управление

- `+` / `−` или стрелки вверх / вниз — изменить глубину рекурсии.
- Колесо мыши — приблизить или отдалить изображение.
- Кнопка «Иллюзия приближения» — запуск или остановка анимации.
- Боковая панель позволяет выбрать палитру и включить переливание цветов.
- `0` — сбросить масштаб.

Глубина ограничена значением 7.

## Структура проекта

- `main.py` — точка входа.
- `tsquare_app.py` — окно, управление и анимация.
- `fractal.py` — построение фрактала.
- `palettes.py` — палитры и выбор цвета.
